🍕 Slice Heaven Pizza

Welcome to Slice Heaven Pizza, a modern and fully responsive restaurant website built using HTML, CSS, and JavaScript. This project is designed to provide a premium user experience with a clean interface, smooth animations, and a mobile-friendly layout. It can be used as a portfolio project or as a template for restaurant and food business websites.

✨ Features

- Responsive design for mobile, tablet, and desktop
- Sticky navigation bar
- Attractive hero section
- Pizza menu with stylish cards
- About section
- Customer reviews
- Contact section
- WhatsApp floating button
- Smooth scrolling and animations
- Clean and organized code

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📱 Responsive Design

The website is optimized for different screen sizes to ensure a smooth browsing experience across all devices.

🚀 Getting Started

1. Clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

No installation or additional dependencies are required.

📂 Project Structure

- "index.html" – Main webpage
- "style.css" – Website styling
- "script.js" – Interactive functionality

🎯 Purpose

This project was created to demonstrate front-end web development skills and modern website design. It can be customized for any restaurant or food-related business.
